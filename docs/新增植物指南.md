# 新增植物完整指南

## 架构概览

```
注册层 → 条件层 → 卡片UI层 → 种植逻辑层 → 植物逻辑层 → 场景层
```

---

## 步骤一览（以新增 `P050PeaShooterTriple` 为例）

### 第1步：注册植物类型枚举

**文件**: `scripts/autoload/global/character_registry.gd:75`

在 `P049PeaShooterDoubleReverse` 之后、`P999Imitater` 之前新增：

```gdscript
P050PeaShooterTriple,
```

---

### 第2步：注册植物信息字典

**文件**: `scripts/autoload/global/character_registry.gd:528`

在 `P049PeaShooterDoubleReverse` 的 PlantInfo 条目之后、`P999Imitater` 条目之前新增：

```gdscript
PlantType.P050PeaShooterTriple: {
    PlantInfoAttribute.PlantName: "PeaShooterTriple",
    PlantInfoAttribute.CoolTime: 7.5,
    PlantInfoAttribute.SunCost: 300,
    PlantInfoAttribute.PlantConditionResource : preload("res://resources/character_resource/plant_condition/000_common_plant_land.tres"),
    PlantInfoAttribute.PlantScenes : preload("res://scenes/character/plant/plant_050_pea_shooter_triple.tscn")
    },
```

**说明**:
- `PlantName`: 英文名（对应图鉴JSON的key）
- `CoolTime`: 冷却时间（秒）
- `SunCost`: 阳光消耗
- `PlantConditionResource`: 种植条件资源（见步骤7）
- `PlantScenes`: 植物场景预加载路径

---

### 第3步：注册到可选植物列表

**文件**: `scripts/autoload/global/global_game_state.gd:81`

在 `P049PeaShooterDoubleReverse` 之后新增：

```gdscript
CharacterRegistry.PlantType.P050PeaShooterTriple,
```

---

### 第4步：创建植物脚本

**新建文件**: `scripts/character/plant/plant_050_pea_shooter_triple.gd`

参考 `plant_001_pea_shooter_single.gd` 的最小模板：

```gdscript
extends Plant000Base
class_name Plant050PeaShooterTriple

@onready var attack_component: AttackComponentBulletBase = $AttackComponent

func ready_norm_signal_connect():
    super()
    signal_update_speed.connect(attack_component.owner_update_speed)
```

**如果是特殊植物**，可重写以下方法（参考 `plant_000_base.gd`）：

| 方法 | 用途 | 示例 |
|------|------|------|
| `ready_norm()` | 正常初始化 | 土地雷需要时间出土 |
| `_be_zombie_eat_once_special()` | 被啃时特殊效果 | 大蒜改变僵尸行进方向 |
| `character_death()` | 死亡时特殊效果 | 樱桃炸弹爆炸 |
| `coffee_bean_awake_up()` | 咖啡豆唤醒 | 蘑菇类白天睡觉 |

---

### 第5步：创建植物场景

**新建文件**: `scenes/character/plant/plant_050_pea_shooter_triple.tscn`

参考 `plant_001_pea_shooter_single.tscn` 结构：

1. 继承 `plant_000_base.tscn`
2. 添加纹理（Body节点下各部位的Sprite2D）
3. 添加动画（Head_Idle / Head_Attack 等 Animation）
4. 添加组件节点：
   - `AttackComponent` (AttackComponentBulletBase) — 射击类植物
   - 或其他组件（AreaComponent 等）
5. 附加脚本（第4步创建的 .gd 文件）

---

### 第6步：准备植物纹理资源

**目录**: `assets/reanim/`

需要准备的图片文件（参考 PeaShooter 系列命名规则）：

| 文件名 | 用途 |
|--------|------|
| `YourPlant_Head.png` | 头部 |
| `YourPlant_blink1.png` | 眨眼帧1 |
| `YourPlant_blink2.png` | 眨眼帧2 |
| `YourPlant_mouth.png` | 嘴巴 |
| `YourPlant_stalk_bottom.png` | 茎底部 |
| `YourPlant_stalk_top.png` | 茎顶部 |
| `anim_sprout.png` | 花蕾/发芽帧 |

---

### 第7步：种植条件资源（如有需要）

**通用陆地植物**: 直接复用已有资源：
```
res://resources/character_resource/plant_condition/000_common_plant_land.tres
```

**特殊植物**: 需新建 `.tres` 文件到 `resources/character_resource/plant_condition/`

现有条件资源参考：

| 文件 | 适用植物 | 特殊条件 |
|------|----------|----------|
| `000_common_plant_land.tres` | 大部分陆地植物 | 草地(2)+花盆(4)+睡莲(16)=22 |
| `000_common_purple.tres` | 紫卡升级植物 | 紫卡标记 |
| `005_potato_mine.tres` | 土豆雷 | 特殊种植判定 |
| `012_grave_buster.tres` | 墓碑吞噬者 | 只能种在墓碑上 |
| `017_lily_pad.tres` | 睡莲 | 只能种在水面 |
| `020_tanglekelp.tres` | 海草 | 只能种在水面 |
| `022_caltrop.tres` | 地刺 | 地刺位置 |
| `031_Pumpkin.tres` | 南瓜壳 | 保护壳位置 |
| `034_flower_pot.tres` | 花盆 | 屋顶花盆 |
| `036_coffee_bean.tres` | 咖啡豆 | 只能种在睡觉植物上 |
| `048_cob_cannon.tres` | 玉米加农炮 | 双格植物 |

**条件资源脚本**: `scripts/resources/plant_condition/condition_000_plant_base.gd:7`

关键属性：
```gdscript
@export_flags("1 无", "2 草地", "4 花盆", "8 水", "16 睡莲", "32 屋顶/裸地")
var plant_condition:int = 22        # 地形条件位掩码

@export var place_plant_in_cell: CharacterRegistry.PlacePlantInCell  # 格子位置

@export var is_special_plants := false   # 是否特殊植物
@export var is_purple_card := false      # 是否紫卡
```

### 第8步：图鉴数据

**文件**: `data/almanac_data.json:4`

在 `"Plant"` 对象中新增（key需与 PlantInfo.PlantName 一致）：

```json
"PeaShooterTriple": {
    "名字": "三线射手",
    "描述": "三线射手，一次发射三颗豌豆，分别攻击上中下三行的僵尸",
    "参数": {
        "伤害": "中等",
        "攻击范围": "三行"
    },
    "简介": "三线射手的灵感来源于...",
    "背景": "Day"
}
```

---

### 第9步：卡牌UI（如有新卡牌）

**文件**: `scenes/autoload/all_cards.tscn`

在对应的 `GridContainer` 节点下新增一个 Card 子节点（prefab）。

**重要**: `AllCards._ready()` 会自动遍历所有子节点收集卡牌，无需改代码，只需添加节点即可。

卡牌节点属性（参考 `scripts/ui/card/card.gd`）：
- `card_plant_type`: 设置为新增的 PlantType
- `sun_cost`: 阳光消耗
- `cool_time`: 冷却时间
- `card_bg`: 卡牌背景纹理

---

### 第10步（可选）：紫卡升级植物

如果是紫卡植物（升级型），需额外修改：

**文件**: `scripts/autoload/global/character_registry.gd:162-171`

在 `AllPrePlantPurple` 字典中新增：

```gdscript
PlantType.P050NewUpgrade: PlantType.P008PeaShooterDouble,  # 前置植物
```

并将种植条件资源设为 `000_common_purple.tres`。

---

### 第11步（可选）：关卡数据

**目录**: `resources/level_date_resource/`

需要编辑关卡 `.tres` 文件，在该关卡的可用植物列表中添加新植物类型。
